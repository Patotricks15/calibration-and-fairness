# Data

German Credit is not committed to this repo. It is loaded by `credit_core.datasets.load_german()`
from the local copy under `~/.local/share/credit-data/german1/german_credit_data.csv`
(source: `kabure/german-credit-data-with-risk`, Kaggle). The data is public. Download it with the
Kaggle CLI and place it at that path before running the notebook.
